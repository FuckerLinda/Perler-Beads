主要功能：

- 内置完整 **MARD 标准 221 色号**
- 导入 JPG、PNG、WEBP，也支持拖放、粘贴图片
- 使用感知色差算法自动匹配实体拼豆色号
- 预设 18×18、29×29、30×30、40×40、48×48、58×58、64×64、80×80
- 支持 5～150 格自定义尺寸
- 支持铺满裁剪、完整显示、拉伸三种模式
- 可限制使用 12、20、32、48、64 种颜色
- 支持误差扩散、亮度、对比度和饱和度调整
- 每格显示对应色号，并带行列坐标和每五格加粗线
- 下方自动统计每种色号需要的豆子数量
- 支持画笔、橡皮擦、取色、区域填充、撤销和重做
- 可导出高清 PNG 图纸、用量 CSV、工程 JSON
- 工程可重新导入继续编辑
- 单文件离线运行，图片在浏览器本地处理

直接双击 HTML 即可使用。屏幕显示颜色存在设备差异，购买材料时仍应以手中的 MARD 实体色卡为最终准绳。





Main Features:

- Includes the complete **MARD standard 221-color palette**
- Imports JPG, PNG, and WEBP images, with support for drag-and-drop and image pasting
- Automatically matches image colors to physical fuse-bead color codes using a perceptual color-difference algorithm
- Provides preset pattern sizes: 18×18, 29×29, 30×30, 40×40, 48×48, 58×58, 64×64, and 80×80
- Supports custom dimensions ranging from 5 to 150 cells
- Offers three image-fitting modes: fill and crop, fit entire image, and stretch
- Allows the palette to be limited to 12, 20, 32, 48, or 64 colors
- Supports error-diffusion dithering and adjustments for brightness, contrast, and saturation
- Displays the corresponding color code in each cell, with row and column coordinates and bold gridlines every five cells
- Automatically calculates the number of beads required for each color code
- Provides brush, eraser, color picker, area fill, undo, and redo tools
- Exports high-resolution PNG patterns, bead-quantity CSV files, and project JSON files
- Saved projects can be imported again for further editing
- Runs offline as a single HTML file, with all images processed locally in the browser

Simply double-click the HTML file to use it. Colors may appear differently across screens and devices, so your physical MARD color chart should always be used as the final reference when purchasing materials.
